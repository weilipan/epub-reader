# EPUB 閱讀器

## 📖 介紹
這是一款基於 `Python` 和 `Tkinter` 的 **EPUB 閱讀器**，允許使用者開啟 EPUB 電子書，並提供以下功能：

- 📂 **開啟 EPUB 檔案**
- 📑 **目錄功能**（可顯示/隱藏）
- 🔄 **切換頁面**（上一頁/下一頁）
- 🔠 **調整字體大小**
- 🌙 **切換深色模式**

---

## 🚀 安裝與執行
### 1️⃣ **安裝 Python**
請確保你的系統已安裝 Python 3.7 以上版本。
[下載 Python](https://www.python.org/downloads/)

### 2️⃣ **安裝必要套件**
執行以下指令來安裝所需的 Python 套件：
```sh
pip install ebooklib beautifulsoup4 pillow
```

### 3️⃣ **運行程式**
下載或複製 `epub_reader.py`，然後執行：
```sh
python epub_reader.py
```

---

## 🛠️ 功能介紹
### 🔹 **開啟 EPUB 檔案**
- 點擊 **「開啟 EPUB」** 按鈕，選擇要閱讀的 EPUB 電子書。

### 🔹 **目錄功能**
- 目錄將顯示在 **左側列表**。
- 使用 **「顯示/隱藏目錄」** 按鈕來切換目錄顯示。
- 點選目錄項目可跳轉到指定章節。

### 🔹 **翻頁功能**
- **「上一頁」**：回到前一頁。
- **「下一頁」**：前往下一頁。

### 🔹 **字體大小調整**
- **「放大字體」**：增大字體。
- **「縮小字體」**：減小字體。

### 🔹 **深色模式**
- **「切換深色模式」** 來改變背景與文字顏色。

## ⚠️ 注意事項
1. 目前僅支援 EPUB 格式，不支援 PDF 或 TXT。
2. 若某些 EPUB 書籍無法正確顯示，請檢查其格式是否符合標準。
3. 深色模式僅影響閱讀區域，不影響 UI 按鈕。
